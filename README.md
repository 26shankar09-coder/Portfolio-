# Ayushi Shankar — Developer & Orator Portfolio 🌌

A bespoke, interactive personal portfolio website showcasing academic pursuits, cybersecurity research, and national oratory leadership. Built entirely from scratch with pure **HTML5, CSS3, and Vanilla JavaScript** — zero frameworks, zero external dependencies.

---

## 🚀 Key Features

* **🌌 Cosmic Deep Space Engine:** Multi-layered HTML5 canvas rendering realistic star clusters, parallax depth, shooting meteors, and drifting cosmic nebulae.
* **✨ Comet Cursor Particle Trail:** Fluid particle dynamics engine following cursor movement with decaying stardust sparks.
* **♾️ Kinetic Moving Infinity Sign:** Custom mathematical SVG path animation with photon beam loop.
* **🎨 10 Aesthetic Universe Themes:** One-click cosmic switcher (or press <kbd>T</kbd>) cycling between *Galaxy Void, Nebula Violet, Supernova Amber, Cyberpunk Neon, Emerald Pulsar, Solar Flare, Deep Abyss, Quantum Aurora, Crimson Eclipse, and Hyper Obsidian*.
* **💻 Interactive Workstation CLI:** Realistic simulated Linux terminal inside a Bento grid supporting interactive commands (`$ internship`, `$ oratory`, `$ contact`).
* **🔊 Web Audio API Sound Engine:** Synthesized audio feedback (chirps and cosmic sound waves) using browser-native oscillators.
* **📱 100% Responsive & Accessible:** Fluid CSS Grid & Flexbox layouts designed for all devices from 4K displays to smartphones.

---

## 🛠️ Tech Stack

* **Markup:** Semantic HTML5
* **Styling:** Modern CSS3 (Custom properties, CSS Grid, Glassmorphism, CSS Animations)
* **Scripting:** Vanilla JavaScript (ES6+, Canvas API, Web Audio API, IntersectionObserver)
* **Dependencies:** None (0 KB external libraries)

## 💻 Running Locally

Simply double-click `index.html` or open it in any modern browser:
```bash
# Or launch a local test server if preferred:
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
